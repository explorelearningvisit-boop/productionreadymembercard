# PulseVault — authoritative dashboard asset library

This directory contains the approved 14-image source pack plus the latest transparent BAD GYM dashboard graphics.

## Added transparent UI graphics
- `16_member_identity_card.webp` — transparent member identity visual, used as the member portrait source in the Flutter dashboard.
- `17_checkin_freeze_header_compact.webp` — transparent check-in/freeze header used in the dashboard top action area.

All Flutter runtime asset references are registered in `pubspec.yaml`. The original 14 approved source assets are retained unchanged.
