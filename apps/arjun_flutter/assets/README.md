# KaamVerse app assets

- Raster illustrations and photographic cutouts must be individual PNG files with a real alpha channel.
- Before adding an asset, verify dimensions, file size, alpha extrema and visible edge quality.
- Do not use contact sheets, full-screen UI collages, screenshot mockups or checkerboard-baked transparency as runtime assets.
- Use Flutter widgets for text, icons, charts, maps/placeholders, controls and dynamic status.
- Record each asset's source, license/permission, purpose and screen usage here.
- This UX phase must not add Firebase/backend dependencies or use remote image URLs as a substitute for approved local assets.
