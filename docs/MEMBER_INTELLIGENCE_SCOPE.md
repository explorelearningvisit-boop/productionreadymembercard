# Member Intelligence UI-first scope

- Recreate the supplied mobile dashboard design using native Flutter widgets and separately managed transparent assets.
- Shared profile, membership progress, journey road and four feature modules: Attendance, Workout, Payment and Body.
- Horizontal tab switching and vertical detail/history navigation.
- Compact 360 logical-pixel layout, responsive larger screens, safe areas, accessibility and no overflow.
- Demo data only. No backend, authentication, payment capture or production API until the UI has been reviewed and accepted.
- Keep source images as source atlases; extract and validate individual assets with a manifest, transparency and license/source tracking.
- Never infer body composition metrics or fabricate AI insights. Do not display auto-renew unless it is a verified opt-in capability.
- Release gate: flutter format, analyze, tests, Android device screenshot and iOS simulator build on macOS.
