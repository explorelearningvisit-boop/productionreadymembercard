# Central Asset Library

This folder consolidates unique visual/font/archive assets found on the current dashboard branch and the earlier purple dashboard branch.

- Originals remain in their source folders/branches; this is a non-destructive library copy.
- Filenames use source commit time converted to IST, context, asset type, descriptive name, and version.
- Files named UNCLASSIFIED_IMAGE require visual review before production use.
- Exact duplicate Git blobs are included only once.
- See `ASSET_INVENTORY.json` for source path, source branch, blob SHA, and destination mapping.

Naming: `YYYYMMDD_HHMMSS_IST_CONTEXT_ASSETTYPE_ASSETNAME_vNN.ext`
