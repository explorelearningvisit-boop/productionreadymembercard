# Material Pack Library

Upload files into the closest matching category. Keep original filenames where practical. Extract ZIPs before uploading; the original ZIP may also be kept in raw-originals.

| Folder | Upload these assets |
|---|---|
| images | Photos, PNG/JPG/WebP artwork |
| icons | SVG/PNG icon sets |
| logos | Brand marks, wordmarks |
| banners | In-app hero banners |
| advertisements | Ad creatives and sponsored placements |
| backgrounds | Backgrounds and gradients |
| textures | Glass, glow, grain, mesh textures |
| borders | Card outlines and strokes |
| frames | Decorative frames and shells |
| badges | Plan, rank, achievement, status badges |
| illustrations | Standalone illustrations |
| animations | GIF and animated WebP |
| lottie | Lottie JSON files |
| videos | Short clips and loops |
| audio | Sound and notification effects |
| fonts | Font files and type families |
| buttons | Button artwork and states |
| cards | Card surfaces and tile artwork |
| charts | Chart decorations |
| graphs | Graph visual treatments |
| maps | Maps, floor plans, location visuals |
| avatars | Member/trainer avatars |
| member-profile | Profile-specific graphics |
| gym-equipment | Dumbbells, machines, fitness gear |
| workout | Exercise and training artwork |
| nutrition | Food and meal graphics |
| attendance | Check-in, calendar, streak graphics |
| payment | Wallet, invoice, transaction graphics |
| membership | Plans, passes, subscriptions |
| qr-codes | QR frames and scan overlays; never real credentials |
| onboarding | First-run illustrations |
| empty-states | No-data/offline illustrations |
| loaders | Loading and skeleton visuals |
| patterns | Repeating motifs |
| stickers | Decorative stickers |
| social-media | Social posts and story creatives |
| offers-promotions | Discounts, coupons, sales |
| ui-components | Reusable UI visuals not covered elsewhere |
| reference | Screenshots, moodboards, design sheets |
| raw-originals | Untouched source packs and original ZIPs |
| misc | Temporary or uncategorized assets |

Never upload API keys, secrets, private member data or real payment credentials. Reference screenshots are guidance, not full-screen app backgrounds. Existing assets in assets/images and assets/fonts are kept separate. New Flutter assets must be registered in pubspec.yaml; SVG/Lottie/video/audio may need extra packages and code integration. After upload, send the exact folder path(s) for inventory and integration.
