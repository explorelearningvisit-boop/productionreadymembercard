# ONE-STOP ASSET DROPZONE

Upload ALL incoming images, icons, banners, fonts, graphics, ZIPs and other design files directly into this folder. Do not sort them first. Keep original filenames where possible.

After upload, tell ChatGPT: **Asset inbox uploaded**. The files will be inventoried and classified into the matching sibling folders under `assets/material_pack/` (images, icons, logos, banners, advertisements, backgrounds, textures, borders, frames, badges, illustrations, animations, fonts, cards, attendance, payment, membership, workout, nutrition, reference, etc.).

Sorting will preserve originals until the categorized copies/moves are verified. Files that are ambiguous will be kept in the inbox and reported for review rather than guessed. ZIP archives may be uploaded here too; they must be extracted before individual assets can be integrated. Large uploads may need to be split into a few batches if GitHub's file-size limits are reached.

Do not upload secrets, API keys, private member data, or real payment credentials. Existing production assets are not overwritten automatically. New Flutter runtime assets must be registered in `pubspec.yaml` before use.
