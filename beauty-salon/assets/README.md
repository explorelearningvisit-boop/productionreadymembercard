# Brand graphics
- `brand/salon-mark.svg`: original leaf/floral salon mark, blush and rose palette.
- `brand/sparkle-pattern.svg`: champagne sparkle motif for decorative surfaces.
Use SVG as scalable source; rasterize to PNG at 1x/2x/3x only when a target surface requires raster assets. Current Flutter scaffold uses Material icon glyphs for UI controls so icon semantics remain accessible.
